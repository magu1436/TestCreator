# 公開デモのサンプル原稿

`samples.json` は公開デモ専用の原稿です。英語50語と古文20語の単語帳を初回投入します。`ocr_samples` は英語帳に未投入の51〜60番の10語で、OCR練習画像の原稿です。

一般的な英単語・古文単語を開発者が選び、日本語の語義をこのデモのために短く自作しました。特定の辞書・教材の説明文、語彙の配列、紙面や画像を転載していません。語義は体験用に一義へ絞ったもので、網羅的な辞書ではありません。

実利用者の単語帳、本番DB、OCR履歴からの抽出は行っていません。アカウント、DBの主キー、認証情報も含みません。このリポジトリの公開とともに配布できる素材として管理します。

各語は `number`（帳内で重複しない正整数）、`term`（30文字以内）、`meaning`（100文字以内）を持ちます。単語帳名は30文字以内です。変更しても投入済みDBには上書きされません。`initial-samples` の投入記録がない新しいデモDBだけに反映されます。
